  - **Cross-Module Telemetry Alignment:** Asserts student enrollment metrics in `/student-oversight` correlate with organization capacity and platform-wide aggregates.

  - **Audit Log Query Deep Linking:** Validates audit log deep-link filtering schema by category, actor, and search query.
  - **Search Palette Entity Aggregation:** Validates that `TopBar` search index indexes both organizations and platform governance workspaces without duplicate keys.
